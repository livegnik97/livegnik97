## 📦 Published Packages

### [event_bus_riverpod](https://pub.dev/packages/event_bus_riverpod) · [![pub package](https://img.shields.io/pub/v/event_bus_riverpod.svg)](https://pub.dev/packages/event_bus_riverpod)

A **type-safe, Riverpod-integrated event bus** for Flutter. Emit and listen to events anywhere in your app with automatic lifecycle management.

**Key features:**
- Type-safe events with generic `T` payloads
- Auto-dispose listeners via `Ref`
- Async support (`listenAsync` / `emitAsync`)
- Sticky events, middleware pipeline, execution priority
- SubEvents, one-shot listeners, event history
- Full integration with Riverpod's dependency injection

### [event_bus_global](https://pub.dev/packages/event_bus_global) · [![pub package](https://img.shields.io/pub/v/event_bus_global.svg)](https://pub.dev/packages/event_bus_global)

The same event bus exposed through a **global singleton** (`EventBusGlobal`) — no Riverpod dependency required. Perfect for plain Dart services, repositories, or apps not using Riverpod.

**Key features:**
- Same feature set as `event_bus_riverpod`
- Manual lifecycle with `ListenerDisposable`
- Works from anywhere: widgets, services, plain classes
- `EventBusBuilder` widget for reactive UI
- Stream API with broadcast mode
